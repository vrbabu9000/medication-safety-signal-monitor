# Hand-in diagram set (30-series)

The diagrams for the hand-in (task C3 in the [hand-in plan](../11-handin/README.md)). They show the pilot as it was built on 2026-11-05 (Compass v35, 13 drugs), updated on 2026-11-06 for D041 v2 (the AI reads 5 labels: 745 / 745 quotes grounded), the deleted duplicate Signal → Drug link type (10 MSSM link types) and Workshop v0.10.0. Older versions are kept unchanged on disk. They replace the pre-build v0 diagrams (01, 02) for anything you hand in. The older diagrams are kept unchanged.

- **PNG / PDF**: rendered from the Mermaid source with `bash tools/render_diagrams.sh`. Use these in reports and slides. All of them are also in [diagram-book.pdf](diagram-book.pdf).
- **draw.io**: an editable copy of the three key diagrams. To get a Visio file, open it in draw.io, then *File → Export as → VSDX*. These files are built by [build_handin_diagrams.py](../../tools/handin/build_handin_diagrams.py), and that script checks the layout first. Each has a preview in [drawio/preview/](drawio/preview/). The preview comes from ReportLab because the draw.io desktop app is not installed, so it may differ slightly from draw.io's own export.
- **Style**: the hand-in palette ([diagram_style.md](../../tools/handin/diagram_style.md)). A dashed border always means "incremental, cached or reused".
